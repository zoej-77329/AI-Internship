# Mini Data Analysis Project

## Objective

The objective of this project is to practice the complete basic data analysis workflow using Pandas and Matplotlib.

The project focuses on loading, cleaning, analyzing, and visualizing a student dataset.

## Dataset

The dataset contains student information including:

- Name
- Age
- Gender
- City
- Category
- Score

The dataset was created for learning purposes.

## Data Cleaning

The dataset was checked for:

- Missing values
- Duplicate records
- Incorrect or inconsistent data

Duplicate records were removed and missing records were handled before analysis.

## Analysis Questions

The following questions were investigated:

1. What is the average student score?
2. Which category has the highest average score?
3. Which city has the highest average score?
4. How many students belong to each category?
5. How are the scores distributed?
6. Is there an apparent relationship between age and score?
