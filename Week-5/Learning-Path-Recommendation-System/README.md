# Learning Path Recommendation System

## Project Overview

The Learning Path Recommendation System is a content-based recommendation application that suggests courses and generates personalized learning paths based on users' existing skills and career goals.

## Objectives

- Analyze users' existing skills.
- Identify missing skills for selected career goals.
- Recommend relevant courses.
- Generate personalized learning sequences.
- Track learning progress.

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib
- Plotly

## Project Structure

- `data/`: Course and career datasets.
- `src/`: Recommendation and data processing logic.
- `components/`: Application interface components.
- `tests/`: Automated tests.
- `docs/`: Project documentation.
- `app.py`: Main application.

## Current Progress

- Project structure created.
- Python environment configured.
- Initial datasets prepared.
- Streamlit application initialized.

## Run the Application

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

Start the application:

```bash
python -m streamlit run app.py
```
